EXPRESS TELEMATICS WEBSITE

Included files:
- index.html
- src/styles.css
- src/main.js
- images/ (logo and website photos)
- favicon.svg

To preview locally:
1. Extract this ZIP.
2. Open a terminal in the extracted folder.
3. Run: python3 -m http.server 8000
4. Visit: http://localhost:8000

The inquiry form opens WhatsApp with the visitor's details prefilled.
